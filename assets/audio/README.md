# Sonidos del escáner

Coloca aquí los dos archivos de audio que usará el escáner móvil:

- `barcode_success.mp3` — sonido corto cuando el producto se reconoce y se agrega.
- `barcode_error.mp3` — sonido diferente cuando el código no corresponde a ningún producto.

No cambies los nombres de archivo. Cuando ambos archivos estén aquí y subidos a `feature/responsive-ui`, se configurarán en `pubspec.yaml` y se conectarán al flujo del escáner.
